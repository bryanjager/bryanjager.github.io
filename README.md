# bryanjager.github.io

Home page and privacy policy for the Google OAuth app **Claude Tasks (personal)**, served by [GitHub Pages](https://pages.github.com/). Google requires both pages, on an authorized domain, before an External OAuth app can be published.

- `index.html` – home page
- `privacy.html` – privacy policy

No secrets or task data live here. The app itself is the private repo `google-tasks-mcp`.
