Privacy Policy – Claude Tasks (personal)

Effective October 11, 2026

Claude Tasks (personal) is a personal tool used only by its developer, Bryan Jager, with his own Google account. It is not offered to anyone else.

Google data accessed

With the permission https://www.googleapis.com/auth/tasks, the app reads and changes task lists and tasks in the signed-in Google account: titles, notes, due dates, completion status, and list names. It requests no other Google data.

How the data is used

Task data is used only to carry out requests Bryan makes in Claude Code on his own computer, such as adding a task or listing tasks due this week. Task content that is part of a request is processed by Claude, Anthropic's AI assistant, as part of that Claude Code session.

Storage

  • The Google sign-in token is stored only on Bryan's computer, encrypted with Windows Data Protection (DPAPI) so that only his Windows account can read it.
  • The app has no server and keeps no copy of task data. Tasks stay in Google Tasks.

Sharing

Google data is not sold, shared with third parties, used for advertising, or used to train AI models. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from Google Account permissions. Revoking access makes the stored token useless.
