Claude Tasks (personal)

Claude Tasks is a personal tool built and used only by Bryan Jager. It connects Claude Code on his own Windows computers to his own Google Tasks account, so he can add, list, update, and complete tasks while he works.

It is not offered to the public. Nobody else can sign in to it or use it.

How it works

  • A small program runs on Bryan's computer and talks to the Google Tasks API with the single permission https://www.googleapis.com/auth/tasks.
  • There is no server and no website behind it. This page exists because Google requires a home page and a privacy policy for every published sign-in app.
